# COSC2669-Fraud-Detection-Analysis
Machine learning analysis for fraud detection using Decision Tree and Neural Network models.

# Fraud Detection Machine Learning Analysis

This repository contains the machine learning experiments conducted for
COSC2669 Case Studies in Data Science.

## Models
- Decision Tree Classifier
- Multi-Layer Perceptron (MLP) Neural Network

## Datasets
- Credit Card Fraud Detection
- Vehicle Insurance Claim Fraud Detection

## Evaluation Metrics
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix

## Files
- fraud_analysis.ipynb - machine learning experiment
- model_results.csv - model evaluation results
